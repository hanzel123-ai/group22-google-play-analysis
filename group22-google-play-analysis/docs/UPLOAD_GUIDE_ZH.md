# Group22 GitHub 上传说明

建议新建独立仓库，名称 `group22-google-play-analysis`，描述可填写：

> Collaborative CA6002 assignment by Group 22 on Google Play app ratings, regression modelling and data visualisation.

1. 解压项目包，进入包含 README.md 的项目目录。
2. 在 GitHub 创建仓库，选择所需可见性；先不自动添加 README、许可证或 .gitignore。
3. 点击 `uploading an existing file`，先上传根目录的 README.md、requirements.txt、.gitignore 和 docs 文件夹，再提交。
4. 使用 `Add file → Upload files` 分批上传 data、notebooks、results、figures、presentation。整个包超过 100 个文件，分批操作更方便。
5. 每次从项目根目录拖入文件夹，保留目录层级；不要上传 ZIP 或把外层项目目录嵌套进仓库。

建议提交说明：`Organize Group 22 collaborative assignment materials`。

项目署名已明确为 Group22 共同完成，分工依据原 PPT 的负责章节，未推断个人代码贡献。PPT 保留原样，公开前可按 REVIEW_NOTES.md 修订其中的数字问题和邮箱展示。数据原始下载地址与分享授权未确认，确认前可先不上传 data 目录。
